Privacy Policy

What Nyami processes, where it is stored, and how to make a data request.

Effective October 18, 2026

Operator and contact

Nyami is operated by thealiamalia, the Nyami operator. For support, privacy questions, access or correction requests, or deletion requests, contact Nyami’s Discord support server. This policy takes effect on October 18, 2026.

Information processed

Nyami processes information needed to respond to slash commands and operate configured integrations:

  • Discord command and operational information: user, server, channel, interaction, and bot-message identifiers; command names and supplied options; timestamps; permissions used to authorize commands; and delivery/error information. Operational logs include command invocations and may include supplied search queries, media URLs, filenames, message IDs, and error details.
  • Image searches and archives: search phrases, selected filters and engine, source URLs and titles, downloaded image files, file properties, and local filenames. The filenames may include words derived from a search query. Downloaded images are archived on the operator's computer and uploaded to Discord when delivery succeeds.
  • Image delivery history: a Discord user or channel scope, image URLs, content/pixel fingerprints, and delivery timestamps used to prevent repeated results. Private replies use per-user history; public channel replies use per-channel history.
  • Video searches: query information, source links, titles, and thumbnail metadata used to build result cards. The current video command does not download or archive video files.
  • Twitch subscriptions and summaries: the Discord server/channel and card-message IDs, Twitch broadcaster IDs and logins, public profile information, current stream identifiers and metadata, preview/category artwork URLs, tags, observed title/category changes, sampled viewers, and relevant timestamps. These records allow a card and its statistics to resume after a restart.
  • Optional OBS controls: authorized command parameters, such as scene or input names, and connection or operation status for the operator's configured OBS instance.
  • Browser search profile: when browser searching is enabled, Nyami uses a dedicated local Vivaldi profile. That browser and the search providers may retain searches, cookies, cache, site preferences, and session data under their own behavior and policies.

The implemented features do not archive a general chat transcript. Discord's client library processes connection/event information needed to operate the bot. End users are not asked to provide their Discord password or bot token to use a command.

Why information is used

Information is used to authorize commands, find and deliver requested content, maintain configured Twitch cards, avoid repeated image results, operate configured integrations, diagnose failures, and provide support. Nyami's current implementation does not contain advertising, data-sale, or model-training functionality.

External services and visibility

Discord processes command interactions, receives bot replies and attachments, and controls their visibility and storage. A public reply can be seen by people who can access its channel. A private Discord reply has more limited visibility in Discord, but its associated image files, history, and logs can still be stored by the bot operator.

Search phrases, filters, and relevant website restrictions are sent to the configured search provider, such as Bing, Google, or an enabled SearXNG service and its upstream engines. Media/source websites receive network requests when Nyami resolves or downloads requested results. Twitch receives public channel lookup and stream-status requests. Authorized OBS commands go to the configured OBS endpoint. These services may process network information and other data under their own policies. People opening source links or watching Twitch also interact directly with those services.

This policy website is hosted on GitHub Pages. GitHub logs visitor IP addresses for security purposes. These pages do not add analytics scripts, tracking pixels, or advertising cookies. GitHub’s own processing is described in the GitHub Privacy Statement.

Storage and retention

The current installation stores its database, downloaded image archives, browser profile, settings, and operational logs locally on the operator's computer. Operator credentials are kept in private configuration and are not included in public policy pages.

There is currently no automatic expiry schedule for the local image archives, image delivery-history database, browser profile, or log files. They remain until the operator removes them. Twitch tracker records retain the current state for each configured subscription; /twitch remove deletes that subscription's active database row but does not erase independent operational logs or an existing Discord card. Large stream timelines are bounded in the implementation.

Stopping the bot or removing it from a Discord server does not itself delete stored images, logs, or image history. The operator must review continued need for retained records and handle deletion when they are no longer needed, when the service is discontinued, and when a valid deletion request or applicable obligation requires it. Deletion is handled manually by the operator.

Access, correction, and deletion requests

Use Nyami’s Discord support server to request access, correction, or deletion of information associated with Nyami. Include your Discord user ID and the relevant server/channel, message, or command details so the operator can identify the records and verify the request. Avoid submitting passwords or tokens. Where a record concerns a server rather than a single individual, the operator may need to confirm the requester's authority over that server.

The current process is manual: the bot does not provide a general self-service privacy-deletion command. The operator can remove applicable bot-controlled local records and files and address bot messages where the bot still has permission to do so. Source websites, Twitch, Discord, other users' copies, and any independently retained copies are controlled by their respective operators; this policy does not claim control over their retention.

Safeguards and updates

The current setup keeps credentials out of ordinary public bot responses and excludes private configuration, runtime databases, and media archives from source-control tracking. Restricted commands check permissions. Access to the operator's computer, browser profile, credentials, and logs must also be managed by the operator.

Changes to Nyami's processing practices should be reflected on this page with an updated effective date. Contact Nyami’s Discord support server with questions or requests.
