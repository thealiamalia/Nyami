Your choices

AI chat and lasting memory

Lasting memory is off until you choose it. Only approved benign preferences are saved, encrypted and scoped, for up to 30 days. Use /chat memory enabled:False to erase saved preferences and opt out of lasting memory, or /chat forget to erase it once. /nyami preferences controls AI participation and optional discoveries; /privacy provides preview, export and deletion controls.

Image analysis and generation run locally. Automatic discoveries and cloud text sharing require separate individual opt-ins. Explicit searches send the requested query to external providers. Private Discord replies and local cleanup do not erase every independent copy.
